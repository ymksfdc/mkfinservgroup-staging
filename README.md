# Mk FinServ™ – Staging Environment

This repository serves as the staging (pre-production) environment for the Mk FinServ™ website.

🔗 https://staging.mkfinservgroup.com

---

## 🧪 Purpose

This environment is used for:

- UI updates
- Feature testing
- Design validation
- Bug fixes
- Pre-release verification

---

## 🔁 Workflow

1. All new changes are made in this repository.
2. Changes are tested thoroughly.
3. Once approved, updates are promoted to the production repository.

---

## ⚠ Important

This is a testing environment.
Do not treat this repository as live production.
